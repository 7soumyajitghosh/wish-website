# A Journey of Love — From a Seed to a New Beginning ✨🌸

A breathtaking, cinematic interactive web experience inspired by the 16-stage journey of love: from a tiny glowing seed rooted in the earth, blossoming into a majestic tree of glowing hearts, and soaring across the twilight sky to where love takes flight.

🌐 **Live Demo (GitHub Pages):** [https://7soumyajitghosh.github.io/wish-website/](https://7soumyajitghosh.github.io/wish-website/)  
📦 **Repository:** [https://github.com/7soumyajitghosh/wish-website](https://github.com/7soumyajitghosh/wish-website)

---

## 📖 The 16-Stage Cinematic Journey

1. **Empty Canvas** — A calm, beautiful twilight sunset over rolling misty hills.
2. **Glowing Seed** — A tiny radiant heart seed appears on the soil with sparkling embers.
3. **Roots Emerge** — Delicate golden filigree roots branch down into the earth.
4. **Trunk Begins** — A slender organic trunk starts reaching upward.
5. **Trunk Grows** — The trunk grows taller and thicker with warm sunset rim lighting.
6. **Main Branches** — Four primary boughs extend outward across the sky.
7. **Secondary Branches** — Natural branching multiplies into a balanced arbor canopy.
8. **Fine Twigs** — An intricate network of delicate twigs creates the crown silhouette.
9. **Tiny Buds** — Little glowing buds ignite at twig tips.
10. **Hearts Blooming (1)** — The first wave of soft blush and coral heart leaves unfurls.
11. **Hearts Blooming (2)** — Vibrant ruby and strawberry hearts fill the interior canopy.
12. **Full Bloom** — A lush, dense canopy of over 350 multi-tonal hearts swaying in the breeze.
13. **Wind Begins** — A gentle wind starts; loose petals and hearts begin drifting to the right.
14. **Hearts Fly Away** — Heart leaves detach in an elegant, arching wind vortex heading rightward.
15. **Transition** — A sweeping ribbon of flying hearts swooshes across the screen into the camera.
16. **Where Love Takes Flight...** — The magical destination page appears:
    - Glowing Heart-shaped Sun in the sky
    - Cherry blossom silhouettes framing the twilight
    - Antique Victorian streetlamp with warm glowing lantern light
    - Cozy garden bench overlooking the sunset
    - Winding stone pathway blanketed with glowing rose petals and fairy lights
    - Interactive openable Love Letter
    - Interactive Wish release form (releasing custom glowing hearts up into the Heart Sun)

## ✨ Features & Technology

- **HTML5 Canvas & Procedural Art:** 60 FPS organic tree growth, cubic Bézier branch curvature, dynamic radial sunset lighting, and particle wind physics.
- **Web Audio API Sound Engine:** Procedurally synthesized musical chimes, heartbeat pulses, blooming bells, and ambient breeze (zero external audio file dependencies).
- **Interactive Story HUD:** Timeline scrubber with 16 clickable stage markers, speed controls (0.5x, 1x, 1.5x, 2x), play/pause, and fullscreen mode.
- **Visual QA Reference Inspector:** Built-in modal allowing side-by-side verification against the full 16-panel reference storyboard.
- **Responsive & Retina Ready:** Optimized for desktop, tablet, and mobile portrait/landscape screens with `devicePixelRatio` crispness.
- **Tech Stack:** React 19, TypeScript, Vite, Tailwind CSS, GSAP (Procedural Canvas art & inline SVG icons, zero bloated icon/confetti dependencies).

npm run dev

npm run build
