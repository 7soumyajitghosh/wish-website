# Contributing to Wish Website

Thank you for your interest in contributing to the Wish Website project.

## How to Contribute

1. Fork the repository.
2. Create a new feature branch.
3. Make your changes.
4. Test the changes locally.
5. Create a Pull Request.
6. Clearly describe the changes in the Pull Request.

## Guidelines

- Keep changes focused and simple.
- Follow the existing project structure.
- Keep animations smooth and responsive.
- Test the website before submitting a Pull Request.

## Project Focus

The Wish Website focuses on creative interactive animations and a smooth visual experience.
